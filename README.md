# portfolio-ds

*Leia em: [English](README.en.md)*

Portfólio de projetos, novos e antigos, que aplicam técnicas de Data Science e automação para resolver problemas.

## Projetos

| Projeto | O que faz | Tecnologias |
| --- | --- | --- |
| [Job Finder](job-finder/) | Busca vagas todos os dias em 8 fontes (Remotar, Gupy, LinkedIn, Glassdoor, InfoJobs, Vagas.com, empresas de dados de futebol e Jobs In Football), classifica por categoria e envia por e-mail com futebol e as empresas preferidas primeiro, afinidade com o currículo e as novidades marcadas | Python, Playwright, APIs, SMTP, pytest |
| [mem-ga](mem-ga/) | O Método de Escolha Múltipla como pacote para Python ([PyPI](https://pypi.org/project/memga/)), R ([R-universe](https://safsalles.r-universe.dev/memga)) e MATLAB ([File Exchange](https://www.mathworks.com/matlabcentral/fileexchange/185196-memga-multiple-choice-method-for-selecting-sets-of-alternatives)), com duas regras de nota, busca exaustiva e algoritmo genético, dois exemplos fictícios e [DOI](https://doi.org/10.5281/zenodo.24062574) | Python, R, MATLAB, algoritmo genético |
| [football-analytics](football-analytics/) | Escalação (MEM-GA) e contratações (GA-MEM) com dados do Brasileirão 2017, a partir da minha dissertação de mestrado, usando o mem-ga | Python, NumPy, algoritmo genético |
| [Gerador de Currículos](gerador-curriculos/) | Gera currículos em PDF em 3 idiomas e versões por área a partir de uma base única da minha carreira, com validação e conferência automática | Python, YAML, python-docx, pytest, Claude Code |
