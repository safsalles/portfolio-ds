# portfolio-ds

*Leia em: [English](README.en.md)*

Portfólio de projetos, novos e antigos, que aplicam técnicas de Data Science e automação para resolver problemas.

## Projetos

| Projeto | O que faz | Tecnologias |
| --- | --- | --- |
| [Job Finder](job-finder/) | Busca vagas remotas todos os dias, filtra pelo perfil e envia as mais recentes por e-mail | Python, Playwright, SMTP |
| [MEM](mem/) | Mostra o Método de Escolha Múltipla puro, sem algoritmo genético, em um exemplo pequeno e fictício | Python, NumPy |
| [MEM-GA](mem-ga/) | Monta um time de futebol para a formação escolhida, com dados do Brasileirão 2017, a partir da minha dissertação de mestrado | Python, NumPy, algoritmo genético |
| [GA-MEM](mem-ga/#ga-mem) | Sugere as contratações que mais melhoram a complementação de um clube, com os mesmos dados do MEM-GA | Python, NumPy |
